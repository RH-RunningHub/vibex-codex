# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it through RunningHub's official private support or security contact and include the affected plugin version, impact, reproduction steps, and any safe supporting evidence.

Do not include access tokens, cookies, private project source, personal data, or production traffic captures. Allow reasonable time for investigation before public disclosure.

## Scope

Security-sensitive guarantees include owner-only project access, exact OAuth resource and scope validation, immutable source revisions, edit leases and fencing, path-scoped patches, short-lived previews, and explicit publication confirmation. The public plugin contains instructions and schemas only; server-side enforcement remains authoritative.
